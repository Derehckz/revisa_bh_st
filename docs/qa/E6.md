# QA — Épica E6 — Deprecar "modo job" en la UI de Operación

## Alcance del cambio
- Se auditó `frontend/src/features/operacion/` completo buscando usos de
  `GenericStagePanel` y `Step0Panel` (paneles de "modo job" genérico, con
  formulario de parámetros crudo + `POST /operations/stages/{n}/start`).
- **Hallazgo**: ambos componentes ya estaban implementados pero **sin ningún
  import activo** en `page.tsx` ni en ningún otro archivo — el tab "Ejecutar"
  ya usa exclusivamente los paneles interactivos supervisados
  (`Stage1InteractivePanel` … `Stage4InteractivePanel`, `BridgedInteractivePanel`
  para 0/5–10). No fue necesario modificar `page.tsx` ni `operacion-tabs.tsx`
  para esto.
- El único punto de la UI que sigue lanzando jobs directamente vía
  `POST /operations/stages/{n}/start` es `close-period-panel.tsx`
  ("Cierre asistido, pasos 2–10"), y **ya vive exclusivamente** bajo el tab
  "Más" (`avanzado`), detrás de un checkbox explícito ("Mostrar cierre
  automático") — no es visible ni accesible desde el flujo feliz de
  "Ejecutar".
- Conclusión: el requisito de E6 ("ocultar/mover el modo job fuera del tab
  Ejecutar, sin borrar los archivos") ya estaba satisfecho por el trabajo de
  una sesión previa. No se eliminaron `generic-stage-panel.tsx` ni
  `step0-panel.tsx` (se mantienen sin usar, disponibles para un futuro modo
  avanzado explícito si se decide reintroducirlos).
- Cambio de esta sesión: ninguno funcional en E6; se documenta el estado
  verificado abajo como checklist de regresión, para dejar constancia de que
  se revisó explícitamente y no quedó "modo job" expuesto en "Ejecutar".

## Frontend
- [ ] Tab "Ejecutar" para cualquier paso (0–10) solo muestra paneles
      interactivos supervisados (con confirmaciones, guía paso a paso,
      streaming de eventos) — nunca un formulario genérico de parámetros +
      botón "Ejecutar paso N".
- [ ] Tab "Más" (`avanzado`) sigue mostrando "Cierre asistido (pasos 2–10)"
      solo si se marca el checkbox "Mostrar cierre automático".
- [ ] `grep -R "GenericStagePanel\|Step0Panel" frontend/src --include=*.tsx`
      solo encuentra las definiciones de los componentes, ningún `import`.

## API
- [ ] `POST /operations/stages/{n}/start` sigue disponible y funcional (no se
      tocó el backend); solo cambia la superficie de la UI que lo consume.

## Regresión
- [ ] `npx tsc --noEmit -p frontend/tsconfig.app.json` sin nuevos errores
      relacionados a Operación.
- [ ] Flujo manual: abrir Operación → Ejecutar paso 0 → paso 1 → … usando
      solo los paneles interactivos, sin encontrarse con el modo job.
